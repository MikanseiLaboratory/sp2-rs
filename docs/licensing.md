# ライセンス方針

最終更新: 2026-09-15

本ドキュメントは、Spout2 / Syphon を Rust で再実装・公開し、さらに商用製品 (eiviz) に組み込む際のライセンス上の整理を記載したものです。
法的助言ではありません。最終的な判断は法務担当者の確認を推奨します。

## 1. 参照元プロジェクトのライセンス

| プロジェクト | ライセンス | 著作権者 | 要件 |
| --- | --- | --- | --- |
| Spout2 | BSD 2-Clause | Lynn Jarvis (2014-2025) | 1. ソース再配布時に著作権表示・条件・免責を保持 2. バイナリ再配布時に同内容をドキュメント等に記載 |
| Syphon-Framework | Simplified BSD (3 条項) | Tom Butterworth (bangnoise) & Anton Marini (vade) (2010-) | 上記 2 点 + 3. Syphon Project / 貢献者の名前を書面の許諾なく推奨・宣伝に使用しない |

いずれもパーミッシブ・ライセンスであり、以下をすべて許可しています。

- 改変、再配布 (ソース / バイナリ)
- 商用利用
- クローズドソースでのバイナリ配布
- 他ライセンス (BSD / Apache / プロプライエタリ等) の成果物への組み込み

コピーレフト (派生物のソース公開義務) はありません。

## 2. 本プロジェクト (sp2-rs) のライセンス

- **BSD 2-Clause** を採用します (Spout2 と同一)。
  - 参照元と同じライセンスにすることで、派生物と判断された場合でも条件の整合性を保ちやすく、利用者側の表記管理も単純になります。
  - Syphon の 3 条項目 (非推奨条項) は、Syphon 由来部分に関して引き続き遵守します (`NOTICE` 参照)。
- 著作権表示: `Copyright (c) 2026, MikanseiLaboratory`
- リポジトリルートの `LICENSE` に全文、`NOTICE` に参照元プロジェクトの著作権表示とライセンス全文を掲載します。

## 3. 「再実装」の位置付け

- 本プロジェクトは C++ / Objective-C のソースコードをコピー・リンクせず、公開情報 (ソースコードの読解を含む) から得た **他プロセスから観測可能な挙動** (メモリレイアウト、カーネルオブジェクト名、通知名、メッセージ形式) を Rust で独自に実装します。
- プロトコル・挙動そのものは著作権の保護対象ではないため、この部分は本プロジェクト独自の著作物です。
- ただし、関数構造やコメントまで忠実に翻訳した箇所は「派生物」と見なされる可能性があります。安全側に立ち、**参照元の著作権表示・ライセンス全文を `NOTICE` に掲載し、ソース・バイナリ両方の配布で保持する** 運用とします。これにより派生物と判断された場合でも BSD の条件を満たします。

## 4. eiviz への組み込み (オープンコア / Pro 機能クローズド)

| 形態 | 可否 | 条件 |
| --- | --- | --- |
| OSS 部分 (sp2-rs) をそのまま利用 | 可 | `LICENSE` / `NOTICE` を同梱 |
| クローズドソースの Pro 版バイナリへ静的リンク | 可 | About 画面・同梱ライセンスファイル等に sp2-rs (BSD 2-Clause), Spout2 (BSD 2-Clause), Syphon (Simplified BSD) の表記を含める |
| Pro 版で sp2-rs を改変し、改変部分を非公開にする | 可 | 同上。BSD にはソース公開義務がない |
| 「Spout 公式」「Syphon Project 提供」等の表現で宣伝 | 不可 | 商標・非推奨条項に抵触し得る。「Spout 互換」「Syphon 互換」といった説明的表現は可 |

## 5. 依存クレートのライセンス

| クレート | ライセンス |
| --- | --- |
| `windows`, `windows-core` | MIT OR Apache-2.0 |
| `objc2` 系, `block2`, `dispatch2` | MIT |
| `wgpu`, `wgpu-hal`, `wgpu-types` | MIT OR Apache-2.0 |
| `winit` (examples のみ) | Apache-2.0 |
| `thiserror`, `log` | MIT OR Apache-2.0 |

いずれもクローズドソース製品への組み込みが可能です。バイナリ配布時には `cargo about` / `cargo license` 等で一覧を生成し同梱することを推奨します。

## 6. 商標・名称に関する注意

- 「Spout」は Lynn Jarvis / Leading Edge の、「Syphon」は Syphon Project の名称です。本プロジェクトは公式実装と誤認させないため `sp2` 系のクレート名を用い、README に「非公式のクリーンルーム再実装であり、各プロジェクトとは無関係」である旨を明記します。
- 互換性の説明 (例: "Spout 2.007 compatible sender") は、事実の記述として問題ありません。
